Masters Market reward keys — the second freebie system

Gift links aren't the only freebies. The game also drops Reward Keys — short promo codes posted in social images, videos and livestreams. They don't open with a tap; you redeem them inside the official Masters Market:

How to redeem a reward key

  1. Copy the key exactly as posted — capitalization and symbols matter.
  2. Open the official Masters Market and find the Reward Keys section.
  3. Paste the code, submit, and confirm when prompted.
  4. Open (or return to) Match Masters — the reward appears on the in-game gift screen.

Keys expire on the promotion's schedule, not yours: a livestream key can die within hours, while an event key may last for days — so use new keys the day you see them. Each key works once per account. If a current key errors, double-check the spelling first, then wait a few hours and retry; temporary hiccups happen, but an expired key never comes back.
